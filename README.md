# 🎬 CINEstream

Uma plataforma de entretenimento para explorar filmes, séries e animes em um só lugar, com uma interface moderna e navegação intuitiva.

🌐 **Acesse o projeto:** [CINEstream](https://brenda200.github.io/CINEstream/)

## ✨ Funcionalidades

- 🎥 Exploração de filmes, séries e animes.
- 🔎 Busca de filmes e séries.
- 🔥 Seção de conteúdos em alta.
- ⭐ Listas de conteúdos populares e mais bem avaliados.
- 🆕 Seção de lançamentos.
- ❤️ Área de favoritos.
- 📺 Detalhes dos conteúdos e opções para assistir.
- 📱 Interface voltada para uma experiência de navegação simples.

## 🚀 Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/brenda200/CINEstream.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd CINEstream
   ```

3. Abra o arquivo `index.html` no navegador.

   Você também pode utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
